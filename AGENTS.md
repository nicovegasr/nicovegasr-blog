# Project instructions

## Editorial and working material

- Create drafts, design proposals, image studies, review screenshots, and any
  other editorial or working material in the private studio repository checked
  out in `studio/`, never elsewhere in this repository. If it is missing, ask
  for that checkout before creating the material.
- This repository holds only what the published site uses and its documentation.

## Technical writing

- Before creating or substantially rewriting any technical content for the blog,
  including articles and pills, read and follow
  [`studio/editorial/technical-writing.md`](studio/editorial/technical-writing.md).
- Read the current content and related entries before drafting. Use the guide to
  preserve Nicolás's voice, technical precision, and any planned series continuity.
- The guide lives in the private studio repository checked out in `studio/`.
  If it is missing, ask for that checkout before drafting; do not substitute a
  generic writing style.

## Image generation

- Before generating or editing any image for the blog, read and follow
  `studio/images/images-styles.md`
  (private studio repository checked out in `studio/`; ask for it if missing).
- Treat that document as the evolving source of truth for the blog's visual
  language. When the user gives explicit feedback about an image, apply it to
  the asset and record any generalisable lesson in the guide.
