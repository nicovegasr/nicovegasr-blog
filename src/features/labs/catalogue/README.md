# Labs catalogue

The labs index: one notebook page per lab, with its live preview taped on as a figure and a link to each level.

## Inside

- `LabsPage.astro` and `labs-page.css`: the page.
- `lab-entry.ts`: the `LabEntry` type every lab fills.
- `copy.ts`: the page title, description and labels.

## Notes

- The catalogue only composes: titles, summaries and previews come from each lab.
